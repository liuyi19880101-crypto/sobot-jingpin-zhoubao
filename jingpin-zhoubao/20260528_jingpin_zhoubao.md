## 🔥 本周重点（TOP 5）

1. **Zendesk 发布"自主服务劳动力"愿景 + 按结果计费定价** — Relate 2026 大会（5/19）宣布彻底转型：AI Agent 取代传统 Bot，每次"可验证解决"收费 $2（承诺量 $1.5），直接挑战 Sobot 的座席人工服务和 AI 定价逻辑，值得高度关注。

## 对 Sobot 的战略建议

1. **正面回应 Zendesk 按结果计费的定价挑战**：Zendesk 的 $2/次解决定价会重塑客户的"价值评估框架"。Sobot 应尽快梳理自身 AI Agent 的解决率数据（现有客户 70%+ 独立解决率案例），并建立"Sobot AI Agent ROI 计算器"，在销售材料中与 Zendesk 按结果计费直接对比，抢占客户心智。

2. **借 Intercom 更名为 Fin 的时机，强化"全渠道一体化"差异**：Intercom/Fin 专注 AI Agent 单点，Sobot 是"AI Agent + 人工座席 + 呼叫中心 + WhatsApp SCRM"一体化平台。建议海外内容营销推出对比文章《为什么 AI-only 不够用》，面向已有 Intercom/Zendesk 的企业客户强调一体化优势。

3. **抓住 Freshworks 裁员后的客户迁移窗口**：Freshworks 同时裁员 500 人并产品线收缩，中小客户可能对服务稳定性产生顾虑。Sobot 海外 SDR 可针对 Freshdesk 用户主动开发，重点强调服务稳定性、BPO+SaaS 一体化、WhatsApp BSP 官方资质（Freshworks 不具备）。

4. **跟进沃丰科技进入 IDC 报告的动作**：沃丰入选 IDC AI Agent 报告是重要国内背书。Sobot 应主动接触 IDC、Gartner、Forrester，争取出现在 AI Agent / CCaaS 领域分析报告中，补足分析师关系短板。

5. **关注 Genesys + Salesforce + ServiceNow 三方生态整合**：三家正构建"CRM + ITSM + CCaaS"闭环生态。建议生态团队重点开发 Salesforce ISV 渠道，以 WhatsApp SCRM + 联络中心组合切入大企业客户，形成差异化竞争位置。
