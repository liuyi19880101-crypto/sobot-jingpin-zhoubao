## 对 Sobot 的战略建议

1. **跟进 PAP 开放标准，推动国内 Agent 互联互通话语权布局**
   Genesys 联合 Meta/Sierra 发起的 PAP 标准若成为行业基准，将深刻影响 CCaaS 的 API 集成架构。Sobot 应评估联合信通院或工信部相关机构，在国内发起"客服 AI Agent 互联互通"团体标准倡议，同时提前做 PAP 协议兼容适配，避免未来在出海市场被架构门槛挡在门外。

2. **加速推出"按结果付费"计费方案，抢占国内 AI 变现叙事高地**
   天润融通 H1 AI 收入+133%、毛利率66%，已通过财报数据验证"按工单解决量收费"的商业可行性；Zendesk 海外版也已全面切向按解决量计费。Sobot 应在1–2个垂直场景（如电商售后、金融投诉）先行推出"AI 解决成功才付费"的结果计费包，形成竞争差异化叙事，同时以此倒逼内部 AI 解决率指标的提升。

3. **针对容联七陌流失客户制定专项迁移方案**

4. **以低代码配置化体验应对 Talkdesk Studio 的产品升级压力**
